# Robot Autonomy Lab's Website GitHub Repository

To edit the website, you must first be added to the [Robot Autonomy Lab GitHub organization](https://github.com/RobotAutonomyLab). Please contact **Prof. Wang** or a current lab member to request an invitation. Once you have organization access, follow these steps to configure your permissions:

1. Access the Repository: Navigate to the `ral_website` repository.
2. Manage Access
   * Go to the `Settings` tab in the top navigation bar.
   * Select `Collaborators and teams` from the left-hand sidebar.
   * In the `Manage access` section, click the `Add people` button.
   * Search for and select your personal GitHub account.
3. Set Permissions
   * When prompted to choose a role, select `Admin`.
   * Click `Add to repository` to finalize.

> [!IMPORTANT]
> Admin access ensures you have full rights to push changes and manage site deployments. Use these permissions responsibly!

4. Navigate to [Pages CMS](https://pagescms.org/) website:
   * Click `Sign in with GitHub` and proceed to sign in with your personal GitHub account
   * In `Open a project`, you should see Robot Autonomy Lab organization (if not select it)
   * You should see `ral_website` listed below where you can click `Open` to edit the website

## Media Management Protocol

Before adding content to any page that requires an image, video, or PDF, you must upload the file to its designated media folder. There are **6 media folders** (`Home page media`, `Research page media`, `Our team files`, `Publication files`, `Robot images`, `News images`). See table below for more details. If you want to upload to specific folder, click on the folder, and click `Upload` and select the file you want to upload. **IF UPLOAD FAILS, YOUR FILE IS TOO LARGE, SO REDUCE THE SIZE OF IT!**

| Content Type | Media Folder | File Types |
| :--- | :--- | :--- |
| Home Page Banners | Home page media | Image, Video |
| Research Diagrams/Photos | Research page media | Image, Video |
| Team Photos & Resumes | Our team files | Image, PDF |
| Publication Papers | Publications files | PDF |
| Robot Photos | Robot images | Image |
| News Post Images | News images | Image |

## Editing RAL Website From Pages CMS

There are **8 pages** (`Home Page`, `Research Page`, `Our Team Page`, `Publications Page`, `Robots Page`, `News Page`, `Join Us Page`, `Teaching Page`). The following sections outline step by step guide to edit each of these pages. After you are done editing, just click the `Save` button and the updates should reflect on the website in a few minutes.

### Editing Home Page

`Home Page` is split into three sections: 
* `Home Page Media` where you can add images or videos to the carousell display. If you click `Add an item`, you will be prompted with the file type `Image` or `Video`. Select accordingly, and click `Select from media` (the button beside `Upload`) and select the file you want to add.
* `Home Page Subtitle` where it gives a single sentence explanation of lab goals/vision. This is a `rich-text` input, so you can bold/highlight/italicize sentences just by selecting specific word(s).
* `Home Page Blocks` where you can link to different parts of the website. It is recommended to NOT change any of this except the `Subtitle` part of each of the 4 existing items. A maximum of 4 blocks can be added to this portion.
